# 业界注意力评测与离线策略标定：调研任务

> 本文件保留调研任务范围，不是评分证据本身。已交付[一手证据与离线标定报告](2026-10-25-attention-scores-and-offline-calibration.md)，含矩阵、版本/分母冲突、许可、缺测和更新规程；未复现论文或得到本地效果结论。

## 要回答的问题

是否存在可定期获得、按精确模型版本追踪的注意力/规则遵循/延迟意图评测与公开打分，能够为 pi-agent-recall 的主策略提供离线标定依据？若没有可靠单分数，应采用哪些多维评分、置信度和缺测标记？

## 必须查证的一手来源

从已迁移[研究快照](agent-im/2026-10-24-model-attention-interventions.md)中的 PM-Bench、Remember When It Matters、Drift No More、Lost in the Middle、FlipFlop 开始，重新核查论文原文、作者代码/数据及当前维护状态。进一步查找官方长上下文、持续指令遵循、agent 延迟意图、记忆与多轮行为评测。不把二手榜单摘要当原始分数，不复用未经重新核验的数字。

每项记录：测量对象、任务/模型/宿主条件、指标与分母、版本日期、负例/false-positive、样本量或不确定性、公开数据/API/下载方式、更新频率证据、授权/可再分发性、维护状态、适用边界。

## 预期交付

1. 证据矩阵和当前可用分数（只有能核实原表/数据才列数值），明确不存在、缺测和未核实。
2. 可持续更新的来源清单与手工/外部流水线更新规程；本轮不实现 core 联网、cron 或 daemon。
3. 单分数可行性裁决；必要时采用多维画像：上下文信息利用、持续约束遵循、延迟意图、更新/取消正确性、合法等待/正确停止、提醒后的误行动、成本与延迟。
4. 评分到策略的离线映射建议：行业分数只能产生候选 profile/实验优先级，不能直接覆盖动作或预算。固定 host/model/task/text 后 replay/A-B 验证，保留负例、回退、用户覆盖与删除实验。
5. 缺测/版本不一致时 conservative off/shadow；不同 benchmark 尺度不直接相加，没有经验证权重不包装成权威总分。
